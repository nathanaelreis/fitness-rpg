┌──────────────────────────────────────────────────────────────────────────┐
│                      💡 DICAS IMPORTANTES                                │
└──────────────────────────────────────────────────────────────────────────┘

	🔹 mod_rewrite É ESSENCIAL
	   Sem ele, rotas retornarão 404

	🔹 .htaccess DEVE estar em dist/
	   Se não estiver, SPA routing não funciona

	🔹 REINICIE Apache DEPOIS de alterar httpd.conf
	   Mudanças só aplicam após restart

	🔹 LIMPE CACHE do navegador
	   Use Ctrl+F5 (Windows) ou Cmd+Shift+R (Mac)

	🔹 O PROJETO É UMA SPA
	   Não precisa de PHP, backend, ou banco de dados
